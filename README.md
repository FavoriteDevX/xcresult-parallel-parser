# 🏁 Xcode parallel .xcresult Parser

> A zero-dependency pipeline utility designed to parse binary native Apple `.xcresult` test logs into clean, human-readable GitHub Markdown summaries for CI/CD environments.

## 💡 The Real Utility
Mobile teams running iOS CI/CD struggle with reading test feedback. Instead of manually inspecting heavy binary payloads or downloading raw Xcode artifacts, this tool programmatically extracts test suite failure contexts instantly at the command line.

## Usage Script
```bash
node parser_engine.js
```
